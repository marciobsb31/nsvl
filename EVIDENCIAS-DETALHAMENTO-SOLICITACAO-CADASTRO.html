1. Resumo da História de Usuário

Como usuário do sistema NVSL com permissão de acesso ao módulo Gerenciar Solicitações de Cadastro,

Quero visualizar os dados completos de cadastro de um(a) Solicitante por meio do botão "Detalhar" ou do botão "Detalhar/Avaliar",

Para que eu possa consultar as informações do solicitante e os vínculos de perfil existentes, caso houver.

6. Correções Aplicadas (23/03/2026)

Três divergências menores foram identificadas e corrigidas durante a análise:

Correção 1 — Texto do botão na listagem

Arquivo: GerenciarSolicitacaoCadastroPage.vue

Antes: 'Detalhar/Analisar'

Depois: 'Detalhar/Avaliar'

Motivo: A HU especifica "Detalhar/Avaliar", não "Detalhar/Analisar".

Correção 2 — Cor do indicador "SEM PERFIS VINCULADOS"

Arquivo: PainelDetalharSolicitacao.vue

Antes: .perfis-indicador.sem { background: #f0ad4e; } (amarelo — compartilhava cor com EM ANÁLISE)

Depois: .perfis-indicador.sem { background: #ccc; } (cinza neutro)

Motivo: A HU especifica ⚪ (branco/cinza) para "SEM PERFIS VINCULADOS".

Correção 3 — Mensagens de sucesso ao ativar/desativar

Arquivo: GerenciarSolicitacaoCadastroPage.vue

Antes: "Cadastro ativado com sucesso." / "Cadastro desativado com sucesso."

Depois: "Perfil ativado com sucesso." / "Perfil desativado com sucesso."

Motivo: A ação é sobre perfil vinculado, não sobre o cadastro inteiro.
