Funcionalidade: Troca de Contexto — Sistema NVSL
Data: 11/04/2026

1. Funcionalidade Implementada

Implementada a funcionalidade Troca de Contexto na barra superior do sistema NVSL, permitindo que usuários com mais de um perfil ativo alternem o perfil em uso sem necessidade de novo login. A troca atualiza imediatamente menus, permissões, dados exibidos e registra auditoria completa.

2. Atendimento às Regras de Negócio

# Regra de Negócio Status Como foi implementado
5.1 Botão visível apenas com mais de um perfil ativo ✅ O dropdown "Troca de contexto" aparece automaticamente na barra superior quando o usuário possui dois ou mais perfis ativos
5.2 Ocultar botão para perfil único ✅ Quando o usuário possui apenas um perfil ativo, o dropdown não é exibido
5.3 Exibir lista de perfis ao clicar ✅ Ao clicar no dropdown, é exibida uma lista com todos os perfis ativos disponíveis
5.4 Informações do perfil (nome, esfera, UF, município, órgão) ✅ Cada opção na lista apresenta o nome do perfil e os detalhes: esfera, UF, município e órgão
5.5 Seleção atualiza o contexto ✅ Ao selecionar um novo perfil, o sistema atualiza imediatamente o contexto da sessão
5.6 Atualização de menus, permissões e dados ✅ Após a troca, menus laterais, permissões de acesso e dados da tela são atualizados automaticamente
5.7 Sessão mantida (sem novo login) ✅ A troca de contexto preserva a sessão autenticada — o usuário não precisa fazer login novamente
5.8 Perfil atual identificado visualmente ✅ O perfil em uso é destacado com badge verde "Ativo" e ícone de confirmação na lista
5.9 Somente perfis com status Ativo exibidos ✅ Apenas perfis com status ativo e dentro do período de vigência são listados para seleção
5.10 Registro de auditoria ✅ Cada troca grava log contendo: usuário, perfil anterior, novo perfil, data/hora, IP e navegador

3. Cenários de Teste

Cenário Resultado
Usuário com mais de um perfil ativo acessa o sistema → botão "Troca de contexto" aparece na barra superior Aprovado
Usuário com apenas um perfil ativo acessa o sistema → botão não aparece Aprovado
Usuário clica em "Troca de contexto" → lista de perfis ativos é exibida Aprovado
Usuário seleciona um perfil diferente → sistema atualiza contexto, menus e dados Aprovado
Após a troca → registro de auditoria é gravado com todos os dados exigidos Aprovado

4. Telas Impactadas

  • Barra superior — Adicionado dropdown de troca de contexto ao lado do nome do usuário
  • Todas as telas dependentes de perfil — Conteúdo, menus e permissões são atualizados após a troca

5. Passo a Passo Operacional Validado

  1. Usuário realiza login no sistema via GOV.BR
  2. Sistema identifica que possui mais de um perfil ativo
  3. Dropdown "Troca de contexto" é exibido na barra superior com o perfil atual
  4. Usuário clica no dropdown
  5. Sistema exibe os perfis ativos disponíveis com nome, esfera, UF, município e órgão
  6. Usuário seleciona o novo perfil desejado
  7. Sistema atualiza o contexto da sessão (sem novo login)
  8. Menus, acessos e dados passam a refletir o novo perfil
  9. Troca registrada no log de auditoria
