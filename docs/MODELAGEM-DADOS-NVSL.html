Modelagem de dados — NVSL

Documento derivado das migrações Laravel e dos modelos Eloquent do repositório.
Versão do schema: março de 2026.

1. Visão geral

O banco suporta autenticação via GOV.BR, vínculo de usuários a perfis de acesso com vigência e lotação (UF, município, órgão), permissões granulares por perfil, solicitações de cadastro, auditoria, tokens Sanctum, e cadastros de apoio IBGE (UF/município) e esferas.

2. Diagrama entidade-relacionamento (conceitual)

Observação: Em solicitacoes_cadastro, users e perfil_usuario, UF e município são armazenados como texto (sigla/nome), não como FK para ufs/municipios. As tabelas IBGE servem de referência para o frontend e carga de dados.
